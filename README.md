# 🎓 Student Result Management System

## Overview

The **Student Result Management System** is a Java console-based application that manages student academic records. It demonstrates **Object-Oriented Programming (OOP)** concepts, especially **Encapsulation**, by securely managing student information using private variables, getters, and setters.

---

## Features

- Create a student record
- Add subject marks
- Calculate student grade
- View student details
- Update student name
- Update course name
- Menu-driven console application
- Input validation for marks

---

## Technologies Used

- Java
- Eclipse IDE
- Scanner Class
- Object-Oriented Programming (OOP)

## How to Run

1. Clone the repository.

```bash
git clone https://github.com/Manikantareddykaipu/student-result-management-system.git
```

2. Open the project in Eclipse or any Java IDE.

3. Run `StudentResultProcessor.java`.

4. Enter:
   - Student Name
   - Student ID
   - Course Name
   - First Subject Marks

5. Select an option from the menu to perform different operations.
